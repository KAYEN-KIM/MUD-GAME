# MUD Game 테스트 체크리스트

실기기 테스트를 위한 체크리스트입니다.

## 🔧 사전 준비

- [ ] 서버가 실행 중인지 확인 (`localhost:3000`)
- [ ] PC와 Android 기기가 같은 Wi-Fi 네트워크에 연결되어 있는지 확인
- [ ] Windows 방화벽에서 포트 3000이 허용되어 있는지 확인

---

## 📱 기본 기능 테스트

### 1. 서버 연결 설정

- [ ] 앱 실행
- [ ] 로그인 화면에서 우측 상단 설정 아이콘 클릭
- [ ] "자동 감지" 버튼 클릭
- [ ] 서버 IP가 자동으로 입력되는지 확인 (예: `192.168.219.112:3000`)
- [ ] 저장 버튼 클릭

### 2. 회원가입

- [ ] "회원가입하기" 버튼 클릭
- [ ] 이메일 입력 (예: `test@example.com`)
- [ ] 비밀번호 입력 (예: `password123`)
- [ ] 캐릭터 이름 입력 (예: `TestHero`)
- [ ] "회원가입" 버튼 클릭
- [ ] 회원가입 성공 확인
- [ ] 홈 화면으로 이동하는지 확인

### 3. 로그인

- [ ] 앱 재시작 또는 로그아웃
- [ ] 이메일 입력 (회원가입 시 사용한 이메일)
- [ ] 비밀번호 입력 (회원가입 시 사용한 비밀번호)
- [ ] "로그인" 버튼 클릭
- [ ] 로그인 성공 확인
- [ ] 홈 화면으로 이동하는지 확인

### 4. WebSocket 연결

- [ ] 홈 화면에서 연결 상태 아이콘 확인 (초록색 = 연결됨)
- [ ] 로그에서 "WebSocket 연결 성공" 메시지 확인
- [ ] 로그에서 "인증 성공" 메시지 확인
- [ ] 로그에서 "STATE_SYNC" 메시지 확인

## 🎮 게임 플레이 테스트

### 5. 기본 이동

- [ ] 현재 위치 확인 (예: `GH_GATE`)

- [ ] 방향 버튼 클릭 (예: "동쪽")

- [ ] GLOBAL 채널로 전송되는지 확인

### 7. 파티 생성

- [ ] 파티 아이콘 클릭
- [ ] "파티 생성" 버튼 클릭

- [ ] 파티 정보 표시 확인

### 9. 상점

- [ ] 상점이 있는 방으로 이동 (예: `GH_SHOP`)
- [ ] 상점 아이콘 클릭
- [ ] 상점 아이템 목록 확인
- [ ] 아이템 구매 시도
- [ ] 구매 성공 확인
- [ ] 인벤토리에 아이템 추가 확인

### 10. 퀘스트

- [ ] 퀘스트 아이콘 클릭
- [ ] 사용 가능한 퀘스트 목록 확인
- [ ] 퀘스트 수락 시도
- [ ] 퀘스트 진행 확인
- [ ] 퀘스트 완료 확인
- [ ] 퀘스트 제출 시도

## 🐛 문제 해결

### 로그인 실패 시

1. **에러 메시지 확인**
   - 앱에서 표시되는 에러 메시지 확인
   - 서버 로그 확인

2. **서버 연결 확인**
   - 설정에서 서버 IP가 올바른지 확인
   - `http://<서버IP>:3000/health` 브라우저에서 접속 테스트

3. **자격 증명 확인**
   - 회원가입 시 사용한 이메일/비밀번호 정확히 입력
   - 대소문자 구분 확인

4. **서버 로그 확인**
   - 서버 터미널에서 에러 메시지 확인
   - DB 연결 확인

### WebSocket 연결 실패 시

1. **WS URL 확인**
   - 설정에서 WS URL이 올바른지 확인 (예: `ws://192.168.219.112:3000`)
   - `http://`가 아닌 `ws://`로 시작해야 함

2. **방화벽 확인**
   - Windows 방화벽에서 포트 3000 허용 확인

3. **네트워크 확인**
   - PC와 기기가 같은 Wi-Fi에 연결되어 있는지 확인
