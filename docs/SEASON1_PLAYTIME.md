# ⏱️ 시즌 1 플레이 타임(2~3주) 검증 메모

이 문서는 “시즌 1을 레벨 1→50으로 올리는데 2~3주가 걸리게”라는 목표가 현재 수치로 **가능한지**를 빠르게 검증하고, **조정 레버**를 정리합니다.

---

## ✅ 현재 코드 기준 핵심 수치(근거 파일)

- **레벨 캡**: 50  
  - `apps/server/src/utils/level-table.ts`
- **레벨 1→50 총 필요 경험치(합산)**: **2,575,500 EXP**
  - `ProgressionService.addExp()`는 레벨업마다 “필요 경험치(레벨별 비용)”를 차감하는 방식
  - `apps/server/src/modules/progression/progression.service.ts`
- **몬스터 처치 EXP 공식**:  
  \[
  \text{expGained} = \lfloor L \cdot 10 \cdot (1 + 0.1L)\rfloor = \lfloor 10L + L^2 \rfloor
  \]
  - `apps/server/src/modules/combat-tick/combat-tick.worker.ts`

### 몬스터 레벨별 1킬 EXP(예시)

- L1: 11
- L5: 75
- L10: 200
- L20: 600
- L30: 1200
- L40: 2000
- L50: 3000

## 🎯 “2~3주”가 되려면 어느 정도 시간이 필요한가(거칠게)

머드 게임은 “전투만”이 아니라 이동/채집/상점/파티/던전/대화가 들어가므로, 아래는 **순수 전투 기반 하한** + **현실적 오버헤드**로 봅니다.

### 가정 A (하드코어/효율 플레이)

- 평균 EXP/킬: 900~1200 (레벨대가 올라갈수록 증가)
- 킬/시간: 120~180 (자동/파티/사냥 루프 최적화)

**필요 킬 수(대략)**  
- 2,575,500 / 1200 ≈ 2147 kills  
- 2,575,500 / 900 ≈ 2861 kills

**순수 전투 시간(대략)**  
- 2147 / 180 ≈ 12.0 시간  
- 2861 / 120 ≈ 23.8 시간

현실적으로는 이동/정비/던전 대기/파티 구성 등으로 1.5~2.5배가 붙으므로:
- **총 18~60시간 범위**가 합리적

### 가정 B (일반 플레이/스토리 읽기/던전 포함)

- 평균 EXP/킬: 700~1000
- 킬/시간: 60~120

**필요 킬 수(대략)**  
- 2,575,500 / 1000 ≈ 2576 kills  
- 2,575,500 / 700 ≈ 3679 kills

**순수 전투 시간(대략)**  
- 2576 / 120 ≈ 21.5 시간  
- 3679 / 60 ≈ 61.3 시간

오버헤드 포함(×1.7~2.7):
- **총 36~165시간 범위**

## ✅ 결론(현재 수치로 “2~3주”는 가능?)

플레이 패턴을 아래처럼 잡으면 “2~3주”가 충분히 가능합니다.

- **2주**: 하루 2~3시간 플레이(주 14~21h) 기준이면, 2주 = 28~42h  
  - 위 “가정 B 하한~중간”에 들어옴
- **3주**: 하루 1.5~2시간 플레이(주 10.5~14h) 기준이면, 3주 = 31.5~42h  
  - 위 “가정 A/B 중간”에 들어옴

즉, 지금 EXP 테이블이 **너무 짧은 편은 아니고**, 오히려 “머드식 루프(던전/제작/강화/길드)”를 제대로 태우면 2~3주를 만들기 쉽습니다.

## 🔧 조정 레버(짧거나 길 때 어디를 만질지)

### 1) 레벨업 난이도(가장 직접적인 레버)

- 파일: `apps/server/src/utils/level-table.ts`
- 방법:
  - 테이블의 상위 레벨(30~50) 구간만 10~30% 조정해 “후반 체감”을 맞춤
  - `MAX_LEVEL = 50` 유지

### 2) 사냥 EXP(게임 체감/파티 메타에 영향)

- 파일: `apps/server/src/modules/combat-tick/combat-tick.worker.ts`
- 현재: `10L + L^2`
- 조정 예:
  - **짧으면**: EXP를 10~25% 감소
  - **너무 길면**: EXP를 10~25% 증가
  - 또는 레벨 차 보정(저레벨 몬스터 효율 감소) 추가

### 3) 스토리/던전/주간 보상 EXP(“주간 루프” 설계 레버)

- 스토리 챕터 보상 EXP(시즌 1 EP01~EP18) 및 던전 레지스트리 보상
- “주간 던전 2회 + 월드 이벤트 1회 + 레이드 1회”만으로도
  - 한 주에 일정 EXP를 ‘확정’으로 지급하도록 설계 가능

## 🧩 아직 “시스템적으로” 남은 것(스토리와 100% 결합하려면)

현재는 스토리/챕터 “완료”가 DB에 저장되지 않아, 앱에서 `completed/canStart/isNext`가 사실상 레벨 기반으로만 동작합니다.

- **스토리 완료/진행 저장(Season Progress 테이블)**  
  - 챕터 완료, 시즌 명성(Season Renown), 선택 분기(강화/재작성/관리) 저장 필요
- **시즌 2~10 성장 축 구현**  
  - 레벨 캡 유지 + 시즌 명성/장비 티어/평판이 실제로 스펙에 반영되게
- **던전/레이드 실제 인스턴스/보스 연동**  
  - 현재는 템플릿/목록 중심 → 보스/드랍/기믹/입장 조건(어튜먼트) 연결
